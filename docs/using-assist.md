Once the server is running with a valid token, this command becomes available:

### **/as ai &lt;prompt&gt;**

This AI command is an assistant for the plugin.

You can ask it to:

* Create a new armor stand
* Remove an existing one
* Change positions, rotations, poses
* More soon...

**Example:**

```
/as ai Create a new armorstand named luna.
```

Or:

```
/as ai Set Luna's armor stand pose to running.
```
