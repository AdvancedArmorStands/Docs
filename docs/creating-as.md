# Create Command

This plugin has so many commands that i can't list there's some examples

`/as create <type> <name>`

the type should be `Default`, `Custom` or your own custom type if set to custom you have to give the properties of the armor stand you want but if you choose any other like default you can just give the name and done.

## Editing an armorstand

To edit an armorstand, you can run `/as settings <name>` or just Shift + Right-click on the armorstand to open its [ArmorStandMenu](armorstand-menu)
