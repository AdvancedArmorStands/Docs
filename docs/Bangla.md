### Unicode Character Encoding

When a language file is generated, non-ASCII characters may be serialized as Unicode escape sequences (`\uXXXX`).

For example, the Bangla text:

```text
অ্যাকশনগুলো
```

may appear in the generated YAML as:

```yaml
actions_menu_title: "\u0985\u09cd\u09af\u09be\u0995\u09b6\u09a8\u0997\u09c1\u09b2\u09cb"
```

This is only a different representation of the same Unicode text. The characters are **not corrupted**, and the YAML configuration will resolve the escape sequences back to the original characters when loaded

This can happen with any language containing non-ASCII characters, such as Bangla, Russian, Chinese, Arabic, or Japanese
